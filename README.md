# CaseOh-s-Basics-in-Eating-and-Fast-Food
CaseOh's Basics in Eating and Fast Food is a highly popular, fast-paced Baldi's Basics parody mod created by Ronezkj15 (the creator behind Raldi's Crackhouse). It centers entirely around the famous streamer CaseOh and the community's running jokes about his love for fast food.
